安装步骤（Windows）

① JDK 17 —— 最省事的做法

不要去官网手动下载再配环境变量，让 IDEA 代劳：装好 IDEA 后，New Project → JDK 下拉框 → Download JDK → 版本选 17、厂商选 Temurin (Eclipse Adoptium) → Download。IDEA 会自动下载并配好。

如果偏好手动装：去 adoptium.net 下载 Temurin 17 的 Windows .msi，一路下一步即可（默认会配好 PATH）。

② IDEA Community

jetbrains.com/idea/download → 页面往下滚，找 Community Edition（免费，页面上默认推的是收费的 Ultimate，别装错）。安装时勾选「Add "bin" folder to the PATH」和 .java 文件关联。

③ MySQL 8

dev.mysql.com/downloads/installer → 下载体积大的离线版（mysql-installer-community）。安装要点：

  • Setup Type 选 Server only（Workbench 等工具你不需要，用 IDEA 或命令行连库就够）
  • 配置一路默认（端口 3306）
  • 设置 root 密码——用你不会忘的密码并记下来，0004 课配置数据源时要填它
  • 装完在开始菜单搜「MySQL 8.0 Command Line Client」能打开、输密码能进入 mysql> 提示符，即成功

    • 怎么打开 MySQL —— 三种门，任选其一

    方式怎么进适合场景
    开始菜单客户端开始菜单搜「MySQL 8.0 Command Line Client」→ 窗口里直接输 root 密码（输入时不显示字符，输完回车即可）→ 出现 mysql> 即进入最省事，第一次就用它
    PowerShellmysql -u root -p → 回车 → 提示 Enter password: 时输密码需 MySQL 的 bin 目录在 PATH 里（安装时没配会报「不是内部或外部命令」）
    IDEA Database右侧 Database 面板 → + → Data Source → MySQL0004 课配置数据源时会用，今天先不管

    进去之后所有命令都以分号 ; 结尾（分号是「执行」的意思，少了它提示符会变成 -> 等你继续敲）。退出用 exit 或 quit。

    连不上时先查服务 报「Can't connect to MySQL server」多半是 MySQL 服务没启动。PowerShell 以管理员身份执行 net start MySQL80（服务名也可能是 MySQL，可在「服务」里搜 MySQL 确认）；或 Win+R 输 services.msc → 找到 MySQL 服务 → 右键启动。

    验收三连（今晚的动手作业）

    ① 跑起第一个 Java 程序

    IDEA → New Project（名字随意，如 hello-java，JDK 选刚下载的 17）→ 在 src 下新建类 Main，敲入：

    public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}

    别手打——这是你的第一个 IDEA 加速 buff：main 里输入 psvm 按 Tab，自动展开 main 方法；输入 sout 按 Tab，自动展开打印语句。点 main 方法旁边的绿色 ▶ 运行，控制台看到输出即过关。

    顺便感受一下类型声明：前端 let msg = "hi"，Java 是 String msg = "hi";——类型在前，语句带分号，语法速通课（0003）会系统讲。

    ② MySQL 建库建表

    用上面三种门的任意一种进入 mysql> 提示符（推荐开始菜单的「MySQL 8.0 Command Line Client」），逐条执行——注意每条都以分号结尾：

    CREATE DATABASE demo DEFAULT CHARACTER SET utf8mb4;
USE demo;

CREATE TABLE book (
    id         BIGINT AUTO_INCREMENT PRIMARY KEY,
    title      VARCHAR(100) NOT NULL,
    author     VARCHAR(50)  NOT NULL,
    status     TINYINT      NOT NULL DEFAULT 1 COMMENT '1上架 0下架',
    created_at DATETIME     DEFAULT CURRENT_TIMESTAMP
);

INSERT INTO book (title, author) VALUES ('深入理解Java虚拟机', '周志明');
SELECT * FROM book;

    看到一行查询结果，即过关。这张 book 表就是 0004 动手课的主角，先替未来的自己铺路。

    常用命令小抄（进库后随手查）

    SHOW DATABASES;              -- 列出所有数据库
USE demo;                    -- 切换到 demo 库
SHOW TABLES;                 -- 看当前库里有哪些表
DESC book;                   -- 看表结构（字段、类型、默认值）
SELECT * FROM book;          -- 查全部数据
INSERT INTO book (title, author) VALUES ('三体', '刘慈欣');
UPDATE book SET status = 0 WHERE id = 1;
SELECT id, title FROM book WHERE status = 1;
EXIT;                        -- 退出 mysql> 提示符

    遇到 -> 提示符：说明上一条语句少了分号，补一个 ; 回车即可；想放弃当前语句输入 \c 回车。

    ③（可选）终端验证

    PowerShell 里执行 java -version，看到 17.x.x 即 JDK 配好了。看不到也没关系——IDEA 内部用自己的 JDK 路径，0004 课全部在 IDEA 里完成。

    课后大作业：打开公司项目

    实战任务（本周最重要的一步） IDEA → File → Open → 选公司项目根目录（有 pom.xml 的那一层）→ Trust Project → 等右下角 Maven 索引进度条跑完（第一次要几分钟）。然后对照 0001 的项目地图，把 controller / service / mapper / entity 四个目录各点开一个文件看一眼。

    大概率遇到两件事，都有解：

    现象解法
    代码大面积红色，Lombok 的 @Data 报「cannot find symbol」Settings → Plugins 装 Lombok 插件（新版 IDEA 自带，确认启用）；Settings → Build → Compiler → Annotation Processors 勾选 Enable annotation processing
    项目 JDK 版本不对（比如公司是 JDK 8）见下面的「多 JDK 共存备查」；同时打开项目根目录的 pom.xml，搜 <java.version>，一眼确认公司的 JDK 版本

    多 JDK 共存备查（公司是 JDK 8 时用）

    IDEA 的每个项目可以独立选 SDK，互不影响：File → Project Structure → Project → SDK 下拉框 → Add SDK → Download JDK → 选 8。你本机的 JDK 17 和 8 可以共存，练习项目用 17，公司项目用 8，切换只在项目设置里改一下。

    小知识 Spring Boot 3 要求 JDK 17+，Spring Boot 2 通常跑在 JDK 8 上。所以「公司的 JDK 版本」基本等于「公司是 Boot 2 还是 3」，这个信息值得汇报给我——影响后面部分代码写法（比如配置文件格式）。

    练习场

    练习 1 · Maven 大致相当于前端的什么？

    解析：Maven 读 pom.xml（对应 package.json）来下载依赖（对应 node_modules 自动生成）、编译打包项目。IDEA 内置了它，所以你不用单独装。

    练习 2 · JDK 和 JRE 的关系，哪个说法对？

    解析：JDK = JRE（运行时）+ javac（编译器）+ 调试工具等。类比：只跑 JS 装 Node 就行，但要「开发」就还需要工具链——Java 的这个开发包就叫 JDK。

    练习 3 · 打开公司项目后 Lombok 注解大面积报红，第一步该干什么？

    解析：Lombok 是编译期生成代码的插件，IDEA 需要两样东西配合：识别注解的插件（新版内置）+ 编译时开启注解处理器。99% 的「Lombok 报红」都是第二个开关没开。

    凭回忆作答（不看上文）

    检索练习是记忆真正的来源——先在心里答完，再点开核对。

    Q1：让 IDEA 帮你下载 JDK 的具体路径是什么？

    New Project → JDK 下拉框 → Download JDK → 选 17 + Temurin。不用手动配环境变量。

    Q2：打开公司项目要选哪一层目录？打开后要等什么跑完？

    选有 pom.xml 的项目根目录；等右下角 Maven 索引进度条跑完再开始看代码。

    Q3：怎么确认公司项目用的 JDK 版本？

    打开 pom.xml，找 <java.version> 标签。Boot 3 对应 JDK 17+，Boot 2 通常 JDK 8。
