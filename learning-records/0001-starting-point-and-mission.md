# 起点：转型决策与已有知识盘点

通过 grilling 确立：用户是熟练 React 前端，Java 零基础，懂 HTTP 与简单 SQL；目标 2027 年年中面试外部中小公司全栈岗（Java 为主 + 前端能写）。公司栈为 Spring Boot 单体 + MyBatis-Plus + Redis + 定时任务，用户下周开始承接后端小需求——工作实战是第一学习驱动轴，教学优先服务实战。Vue 因目标 JD 高频纳入路线（速通级，阶段三）。

**Implications**: 教 Java 用 TS 对比法；八股复习与公司栈一致（MyBatis-Plus 而非 JPA）；第一课必须是"看懂 Spring Boot 单体项目结构"，用户带着真实需求回来时应做成定向 lesson。
