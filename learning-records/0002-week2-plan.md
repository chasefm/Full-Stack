# 第二周规划：环境 + 语法速通 + 第一个 CRUD（grilling 确立）

第二周通过 grilling 确立规划：第一课已完成但用户尚未对照公司项目（公司实战需求也未到位），故走系统课主线。决策链：编辑器定为 IDEA Community 主 + Trae 保留（JDK/IDEA/MySQL 手装、Maven 用 IDEA 内置）；JDK 先装 17，若公司是 JDK 8 走多版本共存备查（信息待用户确认）。课程拆为三门：0002 环境搭建、0003 Java 语法速通（TS 对比法，只教 CRUD 最小集；Stream/Optional/lambda 到"能读懂"级）、0004 图书管理单表 CRUD（Spring Boot + MyBatis-Plus + MySQL + React 页面）。用户明确选择"语法速通全部完成后再动手"。验收方式 = 自测清单全绿 + 导师代码规范 review（结果记入档案）。八股线推迟到第三/四周启动。

**Implications**: 0004 的 review 是第一份 Java 代码的规范基线，重点抓命名、Lombok 用法、构造器注入、异常风格；第三周启动八股时优先 Java 基础 + 集合；期间用户若带来真实工作需求，定向 lesson 优先于周计划。
