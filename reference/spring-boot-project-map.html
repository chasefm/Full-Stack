分层结构

src/main/java/com/company/project/
├── controller/   接收 HTTP 请求，返回 JSON（入口层）
├── service/      业务逻辑（核心层）
├── mapper/       MyBatis-Plus 数据库读写（数据层）
└── entity/       数据表结构（一个类 ↔ 一张表）
Controller → Service → Mapper → MySQL（数据原路返回，自动转 JSON）

注解速查

注解作用
@RestController宣告 HTTP 接口类
@Service宣告业务类，注册进 Spring 容器
@Mapper宣告 MyBatis-Plus 数据访问接口
@Autowired依赖注入：容器自动装配实例
@GetMapping("/path/{id}")GET 路由绑定；同族：@PostMapping 新增、@PutMapping 改、@DeleteMapping 删
@PathVariable取 URL 里的 {id}
@RequestBody把请求 JSON 反序列化成对象（POST body）

MyBatis-Plus 白送的 CRUD

interface UserMapper extends BaseMapper<User>
selectById(id)        // 按主键查
selectList(wrapper)   // 按条件查列表
insert(user)          // 插入
updateById(user)      // 按主键更新
deleteById(id)        // 按主键删除

新增一个接口的改动清单

#动作位置
1加路由方法 + 参数解析controller/XxxController.java
2写业务方法service/XxxService.java
3需要新查询时才写mapper/XxxMapper.java
4表结构变了才改entity/Xxx.java
