变量与类型

TypeScriptJava备注
const n: numberint n / long n / double n整数分档：int（默认）/ long（大数带 L 后缀）
const s: stringString s首字母大写，是对象不是原始值
const b: booleanboolean b相同
constfinal赋值后不可变
类型推断var仅局部变量，Java 10+
null / undefinednull没有 undefined；包装类（Integer/Long）可为 null
5 / 2 === 2.55 / 2 == 2整数除法截断，要小数写 5.0 / 2

字符串

用途JSJava
比内容s1 === s2s1.equals(s2)（== 比的是引用）
长度s.lengths.length()
包含s.includes(x)s.contains(x)
截取s.slice(a, b)s.substring(a, b)
切分s.split(",")s.split(",")
模板串`你好 ${name}`String.format("你好 %s", name)
拼接a + ba + b（同）

集合

用途JSJava
有序列表Array<T>List<T>（new ArrayList<>()）
键值对Record<K, V> / MapMap<K, V>（new HashMap<>()）
添加arr.push(x)list.add(x) / map.put(k, v)
取值arr[i] / obj[k]list.get(i) / map.get(k)
长度arr.lengthlist.size()
遍历for (const x of arr)for (X x : list)
过滤映射arr.filter().map()list.stream().filter().map().collect(toList())
泛型约束Array<T> 任意类型尖括号只能装对象：List<Integer> 不能写 List<int>

类与接口

概念TSJava
类的可见性public / private（编译期）public / private（运行期真强制）
接口绑定结构化类型：长得像就行名义类型：必须显式 implements
接口继承extends类实现接口 implements；接口继承接口 extends
纯数据对象对象字面量直接用POJO 类 + Lombok @Data
覆盖标记无@Override（写错方法名会编译报错）
重载无（可选参数/联合类型替代）同名方法不同参数列表，合法且常见

Lombok 三件套

注解生成什么典型位置
@Datagetter/setter/toString/equals/hashCodeEntity / DTO 数据类
@Slf4j日志对象 log任何要打日志的类
@RequiredArgsConstructorfinal 字段的构造器（→ 构造器注入）Service / Controller

异常

类别代表编译器要求
uncheckedRuntimeException 系列（NPE、IllegalArgument…）无——业务代码随手 throw new RuntimeException(msg)
checkedIOException、SQLException强制 try-catch 或方法签名 throws

公司套路：Service 抛 unchecked → 全局异常处理器（@RestControllerAdvice）统一包装返回。所以很少见到 try/catch。

注解速查（Spring / MyBatis-Plus）

注解人话
@RestController + @RequestMapping("/api/x")路由模块 + URL 前缀
@GetMapping / @PostMapping / @PutMapping / @DeleteMappingURL 绑定到方法
@PathVariable / @RequestParam / @RequestBody路径参数 / 查询参数 / JSON 请求体 → 对象
@Service / @Configuration / @Bean把类/方法返回值注册进 Spring 容器
@Autowired 或 构造器注入（推荐）依赖注入，不用手动 new
@TableName("book") / @TableId(type = IdType.AUTO)实体对应表名 / 主键自增
extends BaseMapper<T>白拿全套单表 CRUD（selectById / insert / updateById / deleteById / selectPage）

lambda / Stream / Optional（读懂级）

// 箭头函数：=> 变 ->
x => x * 2                    ≙    x -> x * 2
x => x.title                  ≙    X::getTitle        （方法引用）

// 链式处理：
list.filter(f).map(m)         ≙    list.stream().filter(f).map(m).collect(Collectors.toList())

// null 安全：
x?.name ?? "默认"              ≙    Optional.ofNullable(x).map(X::getName).orElse("默认")
